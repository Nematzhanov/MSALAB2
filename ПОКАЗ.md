# Шпаргалка для показа ЛР2

Делать **по порядку** — id в запросах рассчитаны на начальные данные после `reset.sh`.

## 0. Подготовка (терминал)

```bash
cd "/Users/mukhammadzahidnematzhanov/claude code/МСА/lab2-spring-java"
tests/manual/reset.sh
tests/manual/services.sh start
```

Открыть вкладки в браузере:

| Что | Адрес |
|---|---|
| Swagger персон | http://localhost:8081/swagger-ui.html |
| Swagger групп | http://localhost:8082/swagger-ui.html |
| Swagger обучения | http://localhost:8083/swagger-ui.html |
| RabbitMQ (guest / guest) | http://localhost:15672/#/queues |

**Как отправить запрос в Swagger:** нажать на запрос → **Try it out** → заполнить id / тело → **Execute**. Ответ и код — ниже, в блоке *Responses*.

## 4. Добавление

**8081 → `POST /persons`**, тело:
```json
{"name":"Анна","surname":"Новикова","birth_date":"2007-04-12","gender":"Ж","snils":"999-888-777 66"}
```
→ 201, `id = 7`.

**8083 → `POST /educations`**, тело:
```json
{"person_id":7,"group_id":3,"start_date":"2025-09-01"}
```
→ 201, `id = 8`, статус «активен».

Сказать: *сервис обучения знает о новой персоне, потому что получил событие `person.created` через RabbitMQ.*

**8082 → `GET /groups/{id}/students`**, id = `3` → в группе 5012 теперь Иванов и Новикова.

## 5. Валидация (замечание преподавателя)

| Swagger | Запрос | Тело | Что будет |
|---|---|---|---|
| 8081 | `POST /persons` | `{"name":"","surname":"Тест","birth_date":"2090-01-01","gender":"X","snils":"12345"}` | 400, все 4 ошибки сразу |
| 8082 | `POST /groups` | `{"name":"9999","start_year":2025,"specialty_id":3,"course":6}` | 400 «курс 6 больше срока обучения специальности (4)» |
| 8082 | `POST /groups` | `{"name":"9999","start_year":2025,"specialty_id":4,"course":1}` | 409 «специальность неактуальна» |
| 8083 | `POST /educations` | `{"person_id":2,"group_id":3,"start_date":"2025-09-01","end_date":"2020-01-01"}` | 400 «дата окончания раньше даты начала» |
| 8083 | `POST /educations` | `{"person_id":2,"group_id":2,"start_date":"2025-09-01"}` | 409 «группа закрыта» |
| 8083 | `POST /educations` | `{"person_id":999,"group_id":3,"start_date":"2025-09-01"}` | 409 «персона с id = 999 не найдена» |
| 8082 | `POST /groups` | `{"name":"4091","start_year":2024,"specialty_id":1,"course":1}` | 409 «нарушена уникальность» (такая группа уже есть) |

## 6. Изменение

**8081 → `PUT /persons/{id}`**, id = `7`, тело:
```json
{"name":"Анна","surname":"Новикова-Орлова","birth_date":"2007-04-12","gender":"Ж","snils":"999-888-777 66"}
```
→ 200.

**8082 → `GET /groups/{id}/students`**, id = `3` → фамилия уже **Новикова-Орлова**.
Сказать: *это каскадное изменение: person-service отправил `person.updated`, group-service обновил свою копию.*

**8083 → `PUT /educations/{id}`**, id = `3`, тело:
```json
{"person_id":2,"group_id":1,"start_date":"2024-09-01","end_date":null,"status":"академический отпуск"}
```
→ 200 (переход разрешён).

**8083 → `PUT /educations/{id}`**, id = `1`, тело:
```json
{"person_id":1,"group_id":1,"start_date":"2024-09-01","end_date":"2025-02-15","status":"активен"}
```
→ 409 «Недопустимый переход статуса: «отчислен» -> «активен»».

## 7. Каскадное удаление

**8081 → `DELETE /persons/{id}`**, id = `7` → `{"message":"Персона удалена","deleted_educations":1}`.

**8083 → `GET /educations`** → записи с `id = 8` больше нет.

Сказать: *person-service удалил персону и отправил `person.deleted`, education-service получил его и удалил её обучение.*

## 8. Мягкое удаление

| Swagger | Запрос | id | Что будет |
|---|---|---|---|
| 8082 | `DELETE /specialties/{id}` | `1` | не удалена, статус «неактуально» (есть группы) |
| 8082 | `DELETE /groups/{id}` | `1` | не удалена, статус «закрыта» (есть обучения) |

## 9. Получатель выключен — сообщение ждёт в очереди

**Терминал:**
```bash
tests/manual/services.sh stop education-service
```

**8081 → `DELETE /persons/{id}`**, id = `2` → 200 (у Петровой одно обучение, id = 3).

**Терминал:**
```bash
/opt/homebrew/sbin/rabbitmqctl list_queues name messages consumers
```
→ `education-service  1  0` — в очереди 1 сообщение, читать некому.

Можно показать и в браузере: http://localhost:15672/#/queues → у `education-service` в колонке *Ready* стоит 1.

**Терминал:**
```bash
tests/manual/services.sh start education-service
/opt/homebrew/sbin/rabbitmqctl list_queues name messages consumers
```
→ `education-service  0  1` — сервис запустился и обработал сообщение.

**8083 → `GET /educations`** → записи с `id = 3` больше нет.

Сказать: *очередь долговечная, сообщение сохранено на диске брокера, поэтому каскад выполнился после перезапуска.*

## 10. Конец учебного года (каскадное изменение)

**8082 → `POST /events/end-of-year`** →
```json
{"message":"Учебный год завершён","groups_promoted":2,"groups_closed":1,"educations_completed":2}
```

**8082 → `GET /groups`** → 3011 «закрыта», 5012 и «1984-до» на курс больше.

**8083 → `GET /educations`** → у записей 5 и 6 статус «завершил обучение» и сегодняшняя дата.

**8081 → `GET /persons/{id}/history`**, id = `4` → Смирнова, группа 3011, «завершил обучение».

Сказать: *group-service закрыл группу и отправил `group.graduated`, education-service поменял статусы студентов.*
